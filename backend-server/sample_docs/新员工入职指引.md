# 新员工入职指引

## 一、入职当天安排

1. 请于入职当天上午 9:00 前到达公司前台，出示身份证原件并领取工牌。
2. 人力资源部专员将陪同完成入职手续，预计用时 1.5 小时。
3. IT 部门在手续完成后发放办公电脑，并协助登录域账号。
4. 直属上级负责介绍团队成员、工位安排及本周工作计划。

## 二、入职需携带材料

| 材料 | 要求 |
| --- | --- |
| 身份证 | 原件及复印件 1 份 |
| 学历学位证书 | 原件，现场核验后归还 |
| 离职证明 | 上一家单位出具，加盖公章 |
| 银行卡 | 本人一类储蓄卡，用于发放工资 |
| 一寸证件照 | 白底电子版，入职前发送至 HR 邮箱 |

## 三、第一周必做事项

1. 当天完成企业微信实名认证，并加入部门群。
2. 入职 3 个工作日内在 OA 系统完善个人信息、紧急联系人。
3. 完成《信息安全》与《员工行为规范》两门线上必修课程，考试成绩不低于 80 分。
4. 与直属上级确认试用期目标，并在系统中提交《试用期目标确认书》。
5. 熟悉考勤打卡：每日通过企业微信打卡 2 次，上班时间为 9:00。

## 四、试用期说明

1. 试用期一般为 3 个月，表现优秀者可申请提前转正，最早为入职满 2 个月。
2. 试用期工资为约定薪资的 80%，转正当月起按全额发放。
3. 转正前 10 个工作日，员工提交述职材料，由直属上级与部门负责人评审。

## 五、常用联系方式

- 人力资源部：分机 8100，邮箱 hr@company.com
- IT 服务台：分机 8000
- 前台：分机 8001
- 行政（工位、门禁、快递）：分机 8300
