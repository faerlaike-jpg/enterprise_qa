# 办公设备与账号管理规范

## 一、办公设备申领

1. 新员工电脑由部门助理在 OA 系统提交《办公设备申领单》，IT 部门审批后 3 个工作日内发放。
2. 标准配置：
   - 研发岗位：高性能笔记本（32G 内存）+ 27 寸显示器 1 台
   - 职能岗位：轻薄笔记本（16G 内存）+ 24 寸显示器 1 台
3. 键盘、鼠标、耳机等外设可在 IT 服务台直接领用，每人每年限领一次。

## 二、设备维修与更换

1. 设备故障请在 IT 服务门户提交报修工单，IT 工程师将在 4 个工作小时内响应。
2. 公司电脑使用满 4 年可申请更换。
3. 人为损坏或丢失设备的，按设备残值由个人承担相应费用。

## 三、账号管理

### 3.1 统一身份账号

1. 员工入职后，IT 部门统一开通域账号，域账号可登录电脑、企业邮箱、OA、VPN 等系统。
2. 初始密码通过企业微信消息发送，首次登录须修改密码。
3. 密码要求：至少 10 位，包含大小写字母、数字及特殊字符，每 90 天须修改一次。

### 3.2 忘记密码

1. 可通过统一身份认证平台（sso.company.com）的「忘记密码」功能，使用绑定手机号验证后自助重置。
2. 自助重置失败的，可携带工牌到 IT 服务台现场重置。

### 3.3 企业邮箱

1. 邮箱地址格式：姓名全拼@company.com，重名时添加数字后缀。
2. 邮箱容量 20GB，单封邮件附件不超过 50MB，超大附件请使用企业网盘分享。

### 3.4 权限申请

1. 系统权限（如代码仓库、财务系统、CRM）须在 OA 中提交《系统权限申请单》，经直属上级及系统负责人审批。
2. 员工转岗或离职时，原有权限将在 1 个工作日内回收。

## 四、离职交接

员工离职须在最后工作日前归还电脑及所有外设，由 IT 部门检查设备完好后在离职交接单上签字。
