# VPN 与网络使用指南

## 一、公司网络说明

1. 办公区提供两个无线网络：
   - **Corp-Office**：员工办公网络，使用域账号认证，可访问内网系统。
   - **Corp-Guest**：访客网络，仅可访问互联网，密码每周一更新并张贴于前台。
2. 有线网络接入须在 IT 服务台登记设备 MAC 地址。
3. 严禁私自架设无线路由器或使用个人热点共享内网。

## 二、VPN 使用说明

### 2.1 适用场景

员工在家办公或出差时，须通过 VPN 访问 OA、代码仓库、财务系统等内网资源。

### 2.2 安装客户端

1. 电脑端：访问内网软件中心或 IT 服务门户下载「Corp VPN 客户端」，支持 Windows 与 macOS。
2. 手机端：在应用商店搜索公司指定的 VPN 客户端，安装后使用域账号登录即可，支持 iOS 与 Android。

### 2.3 登录方式

1. 服务器地址：vpn.company.com
2. 账号：域账号（与电脑开机账号一致）
3. 密码：域密码 + 动态口令（企业微信「身份验证器」中查看 6 位数字）

## 三、常见问题：无法连接 VPN

请按以下步骤排查：

1. 确认本地网络正常，可以正常打开外部网站。
2. 检查 VPN 客户端是否为最新版本，旧版本客户端将被拒绝连接。
3. 确认域账号密码未过期（域密码每 90 天须修改一次）。
4. 确认动态口令输入正确，且手机时间与网络时间同步。
5. 如果使用酒店或机场网络，尝试切换为手机热点。
6. 以上步骤仍无法解决的，请联系 IT 服务台：分机 **8000**，或在 IT 服务门户提交工单。

## 四、网络安全规范

1. 禁止通过 VPN 下载与工作无关的大文件或观看视频。
2. VPN 连接空闲 30 分钟会自动断开。
3. 禁止将 VPN 账号借给他人使用，一经发现将停用账号并通报批评。
4. 发现可疑邮件或钓鱼链接，请立即转发至 security@company.com。
